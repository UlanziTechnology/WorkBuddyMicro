# WorkBuddy · Ulanzi Studio 插件

[English](README.md) · [项目仓库](https://github.com/UlanziTechnology/WorkBuddyMicro)

本文说明 WorkBuddy Micro **1.11.8** 随包提供的功能。源码安装、开发、兼容性记录及授权现状见[仓库 README](https://github.com/UlanziTechnology/WorkBuddyMicro/blob/main/README.zh.md)。连接面板也可打开随包的[使用引导](usage-guide/index.html)。

## 连接 WorkBuddy

「唤起 WorkBuddy」「新建任务」「页面直达」「安装 Skill」通过深度链接直接使用。在属性栏选择国内客户端 `workbuddy://` 或海外客户端 `workbuddy-ai://`，该深度链接路由设置在插件内共享。**CDP 功能当前只面向国内 WorkBuddy 适配，WorkBuddy AI 不在当前 CDP 支持范围内。**

最近任务、模型切换、会话交互、语音、发送、主题和积分需要 CDP。保存工作后，按「启动 WorkBuddy」，或点击功能属性栏中的「重启 WorkBuddy」，等待显示「已连接」。无需命令行、hooks 配置或独立 Bridge 服务。

未连接时，启动键以本地调试模式启动或重启所选客户端，使用 `127.0.0.1:9223`；已连接时唤醒到前台。Windows 重启会结束所选安装目录的进程，包括托盘进程，可能中断任务。9223 端口被占用时会阻止重启；启动后最多等待 30 秒检测连接。

Windows 自动定位检查运行进程、协议注册、用户安装位置、Program Files 和卸载注册表，包含自定义盘符。必要时将 `WORKBUDDY_EXE` 设为客户端完整 EXE 路径，再重启 Studio。

## 深度链接功能

| 功能 | 配置与操作 |
| --- | --- |
| 唤起 WorkBuddy | 打开首页或选定的目标页面。 |
| 新建任务 | 配置提示词模板，可选工作目录、专家、技能、连接器、模型和模式。按下只预填草稿，由你确认发送。 |
| 页面直达 | 选择目标页面；进入指定会话需填写任务 ID。按键图标随目标页面变化。 |
| 安装 Skill | 填写名称和 HTTPS 包地址，在 WorkBuddy 中审阅并确认安装。 |

新建任务支持 `{clipboard}`、`{date}`、`{time}`，例如：

```text
请总结这些笔记并列出下一步行动（{date}）：
{clipboard}
```

工作目录必须是绝对路径。提示词最多 8,000 字符，技能和连接器列表各最多 20 个唯一项。提示词过长时会截断并提示。目标页面包括首页、项目、专家、技能、连接器、自动化、同事、Claw、发现、腾讯文档、本地与云文件、IMA、乐享、邮箱和 Space，是否可用取决于客户端版本、地区和启用的功能。早期 WorkBuddy 5.3.14 验证中，Space 保持当前页面不变，云文件入口进入同一文件列表。

## 最近任务与会话状态

将「WorkBuddy 任务 1–5」放到按键，显示客户端已加载的最多五个最近会话，每个按键跟踪对应会话的状态。按下进入当时键面显示的会话。任务位随最近列表变化，不是永久绑定，也不是完整历史查询。

绿色表示空闲，黄色表示运行，红色表示需要关注，灰色表示断开或不可用。完成提醒要求 WorkBuddy 会话列表存在未读通知；仅变为空闲不会触发完成提醒。

「当前会话状态」是独立的旋钮功能。出现审批时，旋转选择原生提供的操作，例如允许一次、允许此次会话或拒绝，按下执行。不再提供独立的允许、拒绝按键功能。

标准问题框按实际选项选择。屏幕同时显示三行，当前高亮行带 WorkBuddy 标识，长文本以省略号截断。单选遵循原生问题框行为；多选时按下切换各项，再选择提交。原生面板提供翻页或跳过时，也会显示相应操作。选择「其他」将 WorkBuddy 唤醒到前台，自由文本在客户端输入。自定义弹窗可能需要单独适配。

## 模型切换旋钮

连接 CDP 并打开当前会话输入页。旋转选择客户端提供的模型，停下后自动应用；按下立即应用显示中的选择。模型图标和文字一起绘制在圆角卡片中。

切换会话时更新当前模型。审批暂时遮挡输入区时保留上次有效模型；断开连接后显示灰色卡片，没有已知模型时用字母 `N` 占位。可用模型与权限由 WorkBuddy 决定。

## 语音输入与发送消息

「语音输入」开始或结束 WorkBuddy 原生语音输入。只有客户端确认录制后才显示闪烁红点。请在 WorkBuddy 中允许麦克风权限，并保持输入区可用。

「发送消息」在原生发送控件就绪时发送当前草稿，图标同步可用、忙碌、不可用或停止状态。停止图标用于状态反馈，该功能不额外执行停止任务操作。

## 主题切换

1. 在属性栏选择最大 20 MB 的本地 PNG、JPEG 或 WebP 图片。插件会缩放图片并生成低分辨率按键预览。
2. 按需调整正文、辅助文字、面板与输入框、用户消息背景、强调色、选中背景及边框。「恢复图片取色」可恢复自动采样配色。
3. 按主题键应用，再按同一个键恢复 WorkBuddy 原生主题。修改图片或配色后，下一次按键应用新配置。

属性栏也提供「恢复 WorkBuddy 原生主题」。不同主题键可以保存不同配置。样式应用于当前渲染页面，WorkBuddy 重新加载会清除注入的主题。图片和配色保存在 Studio 功能配置中。

## 积分余额

「积分余额」同时支持按键和旋钮，通过 CDP 读取账户剩余积分，每 30 秒刷新，按下立即刷新；旋转不执行余额操作。

首次读取未就绪或临时失败时每秒重试。短暂失败保留上次有效余额，断开连接后清空；没有可读余额时，使用灰色不可用图显示横线。

## 排查与兼容性

实时功能不更新时先检查连接面板。属性栏收不到插件状态时，重新选择功能或重启 Studio。打开 WorkBuddy 确认原生控件是否可用；错误可查看安装目录中的 `debug.log`，反馈前移除私人信息。

按键功能需要兼容的 Keypad 控件；模型切换与当前会话状态需要 Encoder 控件；积分余额支持两者。功能可见不代表实体旋钮兼容性已验证。历史 macOS、Windows 验证记录及待验证的设备和客户端范围见仓库 README。
