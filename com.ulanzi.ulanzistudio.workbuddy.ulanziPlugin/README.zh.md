# WorkBuddy · Ulanzi Studio 插件

用按键唤起 WorkBuddy、预填任务草稿、直达页面、安装 Skill，用旋钮选择模型。

## 直接使用

安装插件 ZIP 后，把动作拖到对应按键或旋钮，在属性面板填写参数即可。唤起、新建任务、页面直达、模型切换、Skill 安装不需要额外服务或前置引导。

- **唤起 WorkBuddy**：默认回到新任务首页，也可选目标页面。
- **新建任务**：只预填草稿，由你确认发送。支持 `{clipboard}`、`{date}`、`{time}`；可选工作目录、专家、技能、连接器、模型和模式。提示词最多 8000 字符；技能与连接器去重后各最多 20 项，超限会提示。
- **页面直达**：项目、专家、技能、连接器、自动化、同事、Claw、发现、腾讯文档、文件、IMA、乐享、邮箱和 Space；打开指定任务需填 ID。页面图标随配置切换。品牌未开放的页面由客户端回退。
- **模型切换**：拖到旋钮，在引导中启用 CDP。打开 WorkBuddy 任务输入页，旋转选择模型，停下后自动应用。
- **安装 Skill**：填写名称和 HTTPS 下载地址；安装确认在 WorkBuddy 内完成。

国内客户端选择 `workbuddy://`，海外包选择 `workbuddy-ai://`。协议选项为插件全局设置。按键支持 D200、D200H、D200X 等 Keypad，模型动作只在 Encoder 控制器显示；不限制设备枚举，以兼容 AU05/Vibe Key 的宿主映射。

## CDP 连接

按「启动 WorkBuddy」以 CDP 模式打开客户端。已连接时唤醒到前台，未连接时启动或重启至 CDP 模式。语音输入、发送消息、当前会话状态与主题切换均提供连接引导。

[使用说明](usage-guide/index.html)

## 排查与开发

状态不变化时，请检查属性栏中的 CDP 连接状态。工作目录必须是绝对路径。

本插件是零运行时 npm 依赖的 Node 主服务，`package.json` 明确使用 CommonJS，避免受到安装目录上层 ES Module 配置影响。宿主 Node 20 可直接运行，不需要构建。

```sh
npm run check
```

将整个 `com.ulanzi.ulanzistudio.workbuddy.ulanziPlugin` 文件夹作为 ZIP 根目录打包。不要丢失目录，也不要修改 ZIP 后缀。

## 素材与验证边界

动作图标和三种状态动画来自用户提供的 WorkBuddy 资料，统一为 196×196；封面为 960×640。设备示意使用 Ulanzi 插件技能中的真实设备素材。品牌和素材权利归原权利人，未授予额外分发许可。

已在本机 macOS 的 WorkBuddy 5.3.14 / Studio 3.4.13 与宿主 Node 20.18.0 验证。Windows、海外包和 AU05/D200X 旋钮真机需在相应环境另行验证，不把模拟协议检查视为真机结果。

## 1.1.1 补充验证

修复空提示词不能打开新任务首页、长剪贴板在 emoji 边界截断导致编码失败及漏提示的问题；唤起时立即反馈，并拒绝非整数模型选择索引。

已验证模拟旋钮事件能让真实客户端从 GLM-5.3-Flash 切回新任务的 Auto。页面直达已逐项检查：当前 WorkBuddy 5.3.14 的 Space 入口会保持当前页面，云文件参数进入同一文件列表；这属于当前客户端的功能表现。

任务 1–5 显示 CDP 读取到的最近会话。按下打开键面上的任务。

「积分余额」支持按键和旋钮，通过 CDP 读取当前账户剩余积分，每 30 秒刷新，按下立即刷新。属性栏提供连接引导。无法读取时显示灰色横线。
